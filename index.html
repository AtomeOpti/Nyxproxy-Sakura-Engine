Depending on your network bandwidth and thread allocation (e.g., 50–100 workers), the engine easily scales from 50 to 300+ requests per second (RPS). Built with non-blocking thread management, it verifies thousands of endpoints in under a minute without memory leaks.

During the verification handshake, the engine inspects HTTP headers like X-Forwarded-For, Via, and Remote-Addr. Proxies revealing zero client IP signatures are categorized as Elite / High-Anonymous, while those exposing headers are flagged as Transparent or Medium.

The checking pipeline measures real-time response latency and HTTP status flags (200 OK vs. 403/503 Cloudflare challenges). You can configure target test endpoints directly inside scraper.py to ensure captured proxies can bypass strict rate-limiters and Web Application Firewalls.

Latency is calculated using precise Round-Trip Time (RTT) benchmarks per ping. Results are dynamically color-coded: ultra-fast nodes (< 500 ms) highlight in mint green, acceptable routes in orange, and slow or degraded endpoints in red.
